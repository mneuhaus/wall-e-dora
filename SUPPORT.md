# Support

## Scope

This repository is the firmware/software stack for my own WALL-E build. It is
public because other people may find it useful, interesting, or worth adapting,
but it is **not** a product with guaranteed maintainer support.

## Where To Ask What

### Use GitHub Discussions for:

- build questions
- hardware and wiring help
- troubleshooting your own robot
- remix / mod ideas
- showcase posts, photos, and videos
- general community exchange

Discussion link:

- <https://github.com/mneuhaus/wall-e-dora/discussions>

### Use GitHub Issues for:

- reproducible bugs in this repository
- concrete implementation tasks
- documentation problems that should be fixed here
- clear feature requests tied to the codebase

## Language

Please use **English only** in Issues and Discussions so the project stays
understandable to the widest possible set of builders.

## Support Expectations

- Community help is welcome and encouraged
- I may answer when I can
- Please do not expect guaranteed turnaround or one-on-one support

## If You Need Help

Please include as much context as possible:

- what hardware you are using
- what you expected to happen
- what actually happened
- logs, screenshots, photos, or video
- what you already tried

That makes it much easier for other builders to help you.
